# 00. PROJECT DEFINITION

## Project Name

**NOIRÉ**

## Tagline

**Chocolate, Unhurried.**

## One-line vision

> Build a cinematic chocolate website that feels like a luxury food film, contemporary fashion campaign, tactile 3D product experience, and modern storefront combined into one continuous story.

## Core objective

The final website must be:

- fully functional
- visually distinctive
- cinematic
- interactive
- responsive
- accessible
- performant
- production-structured
- commerce-ready
- unmistakably custom

It must **not** feel like an AI-generated template.

# 03. ANTI-AI-SLOP MANIFESTO

## Rule 01 — No generic website structure

Do not default to:

```text
Hero
Features
Benefits
Testimonials
Pricing
FAQ
CTA
Footer
```

Every section must have a narrative reason to exist.

---

## Rule 02 — No animation without purpose

Every animation must support:

```text
STORY
HIERARCHY
PHYSICALITY
INTERACTION
MATERIALITY
TRANSITION
```

If it does none of these:

**remove it.**

---

## Rule 03 — No random 3D

Do not use:

- abstract blobs
- floating spheres
- random cubes
- decorative toruses
- meaningless 3D rings
- generic AI blobs
- unrelated geometric objects

3D must belong to the world of cacao and chocolate.

---

## Rule 04 — No purple AI gradients

Avoid generic:

```text
purple
blue
pink
neon
rainbow
```

The palette is warm, dark, edible, tactile and editorial.

---

## Rule 05 — No excessive glassmorphism

Avoid:

```text
frosted panels
glass cards
blurred dashboards
floating translucent boxes
```

The visual language should feel physical rather than software-like.

---

## Rule 06 — No card-grid addiction

Do not turn every idea into a card.

Prefer:

```text
typography
imagery
negative space
lines
cropping
asymmetry
3D objects
```

---

## Rule 07 — No fake luxury

Avoid excessive:

```text
gold
marble
ornaments
royal language
glitter
```

Premium should come from:

```text
spacing
material
typography
lighting
pacing
craft
```

---

## Rule 08 — Typography must survive without animation

Disable motion.

The website should still look intentional and premium.

---

## Rule 09 — Use stillness

Cinematic design needs quiet moments.

Do not animate continuously.

---

## Rule 10 — Remove before adding

Before adding a new visual element:

> What does this contribute?

If the answer is unclear:

**don't add it.**

# 20. SCROLL TIMELINE

## 0–15%

```text
camera far → closer
bean small → larger
text fade in
light begins revealing object
```

## 15–30%

```text
camera moves inward
bean becomes dominant
environment emerges
particles appear
```

## 30–50%

```text
bean → transformed state
process typography
camera travels
lighting changes
```

## 50–70%

```text
chocolate bar appears
camera orbits
light becomes warm
product dominates composition
```

## 70–85%

```text
bar cracks
pieces separate
one piece approaches
```

## 85–100%

```text
scene empties
one piece remains
final statement
CTA
```
