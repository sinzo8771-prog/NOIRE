# NOIRÉ — Baseline Audit & Verification (Phase 0 / Phase 6)

Audit date: 2026-09-06 · Repo: `sinzo8771-prog/NOIRE` · Deployed: `noireee.vercel.app`

## 0. Stack correction (plan assumed React + Vite)

The site is **Next.js 14 App Router** (`next build`, `src/app/`, static prerender), not Vite.
Consequences:

- Hero/product content is already server-rendered into the raw HTML — crawlers see it
  without JS (verified via `Invoke-WebRequest` on the served HTML).
- "Prerender/SSR" (Phase 5) was already satisfied; work focused on metadata completeness.
- `gsap` was installed but **never imported anywhere** — removed.
- No GSAP/ScrollTrigger scroll-jacking exists; scrolling is Lenis (wheel smoothing only,
  native touch) + a ref-driven canvas scrubber.

## 4. Products / commerce reality (Phase 3)

- All 4 SKUs (ORIGIN 72, DARK SEA SALT 70%, ROASTED HAZELNUT 68%, MADAGASCAR MILK 55%) already
  rendered full detail pre-fix: cacao %, tasting notes, palate metrics, terroir, conche/temper,
  ingredients, allergens. No gaps.
- Cart was **fully wired** (localStorage + quantity/remove + simulated "checkout" that only
  cleared state) — removed entirely: `NoireCart`, `useCart`, `formatPrice`, price/currency fields.
- Replaced with reality-matched CTAs: nav "Request a Tasting", product "Request This Bar" —
  pre-filled `mailto:` to concierge@noire-chocolate.com including the selected SKU/flight.
- Shipping/checkout scaffolding (free-shipping threshold, order dialog) deleted.
- Footer "Allergen Declarations" / "Direct Trade Transparency" were dead `<span>`s → now real
  anchored sections with per-SKU allergen statements and sourcing copy.

## 5. Scroll & accessibility (Phase 2)

- Pre-fix: `useReducedMotion` existed but only made the canvas snap frames; it still loaded all
  192 frames, still ran the rAF loop, Lenis still smoothed, CSS animations untouched.
- Post-fix: reduced motion → no Lenis (native scroll), no canvas scrubbing/rAF loop (static
  opening frame), no particle layer, CSS motion neutralized via global media query,
  "Skip to content" link is the first focusable element.
- Canvas gets `role="img"` + descriptive `aria-label`; 3D viewer region likewise labeled.
- Lenis only smooths wheel events; touch/keyboard remain native, so back/forward gestures and
  keyboard navigation are unaffected.

## 6. SEO / technical (Phase 5)

- `robots.txt` / `sitemap.xml`: **404 pre-fix** → now generated by `src/app/robots.ts` /
  `sitemap.ts` (verified serving correct content locally).
- Metadata: added `metadataBase`, `og:image` (1200×630 `public/og-image.jpg`), `og:site_name`,
  Twitter `summary_large_image` card — all present in served HTML.
- Raw served HTML contains the full story content (SSR) — no crawler dependency on JS.
